Interactive Lesson Example: Inspecting File Permissions
$ ls -l $PREFIX/bin/python
-rwxr-xr-x 1 u0_a210 u0_a210 14328 Sep 15 10:42 python
Lesson breakdown: The -rwxr-xr-x string indicates permission flags (Read, Write, Execute). The owner (u0_a210) has full execution access, while group and public users have read and execute rights without write privileges.
